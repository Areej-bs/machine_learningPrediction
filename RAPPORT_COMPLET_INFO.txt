   │  2. Le PDF sera créé automatiquement !                             │

   │  2. Terminal: ./creer_pdf.sh                                       │
   │  3. Le PDF sera créé automatiquement !                             │
   └────────────────────────────────────────────────────────────────────┘

   Méthode 2 - Commande Manuelle:
   ┌────────────────────────────────────────────────────────────────────┐
   │  1. Installez Pandoc:                                              │
   │     Windows: choco install pandoc                                  │
   │     Mac: brew install pandoc                                       │
   │     Linux: sudo apt-get install pandoc                             │
   │                                                                    │
   │  2. Exécutez:                                                      │
   │     pandoc RAPPORT_ML_PARTIE_*.md -o RAPPORT_ML_COMPLET.pdf \     │
   │     --toc --number-sections --pdf-engine=xelatex \                 │
   │     -V geometry:margin=1in                                         │
