## 🚀 Comment Créer le PDF

### Méthode 1: Script Automatique (Recommandé)

**Windows:**
```bash
# Double-cliquez sur le fichier
creer_pdf.bat
```

**Mac/Linux:**
```bash
# Donnez les permissions
chmod +x creer_pdf.sh

# Exécutez le script
./creer_pdf.sh
```

### Méthode 2: Commande Manuelle

```bash
# 1. Installez Pandoc
# Windows: choco install pandoc
# Mac: brew install pandoc
# Linux: sudo apt-get install pandoc

# 2. Créez le PDF
pandoc RAPPORT_ML_PARTIE_*.md -o RAPPORT_ML_COMPLET.pdf --toc --number-sections --pdf-engine=xelatex -V geometry:margin=1in
```

### Méthode 3: Conversion en Ligne

1. Allez sur https://www.markdowntopdf.com/
2. Copiez le contenu de chaque partie
3. Convertissez en PDF
4. Téléchargez
